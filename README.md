# HTML & CSS Interface Practice

## About the Project

This project is part of my journey into web development. It consists of practical HTML and CSS exercises where I recreated selected elements and layouts inspired by popular websites to improve my understanding of webpage structure and styling.

## What I Practised

- **HTML5:** Structuring webpage content using HTML elements.
- **CSS3:** Styling webpage components and layouts.
- **CSS Flexbox:** Practising alignment, spacing and positioning of elements.
- **CSS Transitions:** Exploring transition effects and interactive styling.
- **Button Styling:** Creating and styling different types of buttons.
- **Web Layouts:** Recreating selected product listing and video content interfaces.

## Project Features

- Amazon-inspired product listing featuring Nike black running shoes.
- YouTube-inspired video content section featuring a technology video.
- Different button styles, including Add to Cart, Buy Now, Subscribe and Sign Up.
- A promotional banner with a call-to-action message.

## Technologies Used

- HTML5
- CSS3
- Visual Studio Code

## What I Learned

Through this project, I gained practical experience working with HTML structures, CSS styling, Flexbox layouts and transitions. I also improved my understanding of how different webpage elements are organised and presented.

## Project Status

This is a learning and practice project. It is not a fully functional e-commerce or video streaming website.
